# inbox — your documents

Drop any planning documents here: plan, PRD, user stories, meeting notes, reference links. Sub-folders are fine.

- `.md` or `.txt` work best. See [../README.md](../README.md) for other file types.
- The AI never changes these files. Its results go to `../specs/`.
- After adding or changing a file, ask the AI in the Qwen chat: "Organize my documents into specs."
