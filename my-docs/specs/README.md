# specs — your Spec Kit

The AI writes these files from your notes in `../inbox/` when you ask it to organize your documents. You don't need to open them: the AI asks its questions with choices in the chat and writes your answers here. To change something, tell the AI.

| File | What it says |
|---|---|
| `constitution.md` | The rules for every step: goals, users, principles, tone |
| `spec.md` | What the site does: user stories (P1 = must have), requirements, success criteria |
| `plan.md` | How to build it: Storybook parts, then website pages, their addresses and exact words |
| `tasks.md` | Your steps, in order |
| `sources.md` | The inbox files the AI already read. The kit writes it when the AI finishes. Don't edit it. |

`[NEEDS CLARIFICATION: …]` marks a question for you. Ask the AI "Are there any open questions left?" to list them all. The word list is in [../README.md](../README.md#words-youll-see).
